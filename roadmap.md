# LOOPA Ecosystem — roadmap (según docs/PROMPT_MAESTRO_LOOPA_3D_ECOSYSTEM.md)

## Fase 1 — LOOPA Suite (galería)
- [ ] Miniatura visible en cada tarjeta
- [ ] Fecha de última modificación + creación, tipo/formato, última app usada
- [ ] Ordenar por nombre / fecha de creación / última modificación
- [ ] Confirmación antes de eliminar
- [ ] Cabecera adaptable a pantallas pequeñas
- [ ] Tarjeta de Sculpt en "Ecosistema & Módulos" abre Sculpt de verdad

## Fase 2 — LOOPA Core
- [ ] Registro de apps y áreas de datos que puede modificar cada una
- [ ] Metadatos de ecosistema en el formato de proyecto (última app, historial de sesiones, base de UVs)
- [ ] Firmas por área (topología, forma, transformaciones, UVs, materiales) y detección de cambios
- [ ] Aviso cuando la geometría cambió después de editar UVs
- [ ] Aviso si una app modifica un área que no le corresponde
- [ ] Botón "Compartir con LOOPA Ecosystem" en todas las apps (guardar → abrir mismo proyecto en otra app)
- [ ] Pruebas unitarias de las reglas de Core

## Fase 3 — Apps independientes (siguiente)
- [ ] Modeler sin herramientas de esculpido/UV/materiales
- [ ] Sculpt con interfaz propia (pinceles, tamaño, intensidad)
- [ ] UVs y Materials con solo sus herramientas

## Fase 4/5 — Integración y pruebas end-to-end
- [ ] Flujo completo: crear → modelar → Sculpt → UVs → Materials → cerrar → reabrir, sin pérdida de datos
